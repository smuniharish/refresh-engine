# Benchmarks

`benchmark_refresh.py` measures domain-neutral orchestration with:

- resource counts of 1,000, 10,000, and 100,000;
- unchanged (0), one-change, 100-change, 1,000-change, and full-refresh profiles;
- discovery, fingerprint, detection, execution, and end-to-end timings;
- peak traced memory and maximum observed active operations;
- a fresh baseline before each measured sample;
- configurable repetitions and optional JSON output.

```text
python benchmarks/benchmark_refresh.py
python benchmarks/benchmark_refresh.py --sizes 1000 --profiles unchanged one hundred
python benchmarks/benchmark_refresh.py --repeat 5 --json benchmark-results.json
```

The harness prints raw samples and medians. The repository includes one raw reference
run in `results/windows-python-3.12-2026-09-24.json`, generated by the full default
matrix on CPython 3.12.14 / Windows 11. Run on an otherwise idle machine, retain
environment metadata, and compare only identical versions and options. The source,
snapshots, operation, and state store are in-memory; this isolates engine orchestration
and does not model consumer I/O.

The baseline is excluded from measured time. Cheap indicators make unchanged
profiles representative of the engine's documented pre-check path. Full refresh
forces every resource into the plan even when its fingerprint is unchanged.
